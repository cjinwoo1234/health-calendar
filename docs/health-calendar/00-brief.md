# 건강 캘린더 체크리스트 — 제품 브리프

## 목표

사용자가 매일 자신의 건강 상태를 빠르게 기록하고, 캘린더에서 날짜별 기록과 연속 실천 흐름을 한눈에 확인한다.

## 사용자와 범위

- 대상: 자신의 생활·컨디션을 가볍게 관리하려는 개인 사용자
- 플랫폼: 모바일 우선 반응형 웹앱
- 저장: 서버 없이 브라우저 로컬 저장소를 사용한다.
- 의료 목적: 진단·치료·응급 판단을 제공하지 않는다. 기록 도구임을 명시한다.

## 핵심 경험

1. 오늘 날짜가 기본 선택되고, 수면·수분·식사·운동·기분·증상을 체크한다.
2. 저장 후 캘린더에서 기록 완료 날짜를 시각적으로 확인한다.
3. 날짜를 선택하면 해당 날의 체크 결과와 메모를 다시 보고 수정한다.
4. 이번 주 완료율과 연속 기록을 통해 지속성을 확인한다.

## 기본 체크 항목

- 수면 7시간 이상
- 물 6잔 이상
- 균형 잡힌 식사
- 20분 이상 움직임
- 오늘 기분: 좋음 / 보통 / 힘듦
- 컨디션 메모

## 완료 조건

- 새로고침 후에도 기록이 유지된다.
- 날짜 이동과 저장·수정이 정상 동작한다.
- 모바일 화면에서 주요 조작이 한 화면 안에서 이해된다.
- 접근 가능한 버튼/라벨과 빈 상태 안내가 있다.
