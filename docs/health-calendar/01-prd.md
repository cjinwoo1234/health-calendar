# 건강 캘린더 체크리스트 — PRD

## 화면 구성

- 상단: 서비스명, 오늘로 이동 버튼
- 요약 카드: 선택 날짜, 오늘 완료율, 현재 연속 기록
- 월간 캘린더: 이전/다음 달 이동, 기록 있는 날 표시, 오늘 강조
- 체크리스트 카드: 체크박스 4개, 몸 상태(증상) 항목, 기분 선택 3개, 메모, 저장 버튼
- 하단 안내: 기록은 이 기기에만 저장되며 의료 조언이 아님

## 상태와 규칙

- 날짜 키는 `YYYY-MM-DD` 로 통일한다.
- 체크리스트 완료율은 4개 체크 항목(수면/수분/식사/운동) 중 완료한 수를 기준으로 계산한다.
- 기분과 메모만 입력해도 기록을 저장할 수 있다.
- 기록이 하나라도 있으면 캘린더 날짜에 점을 표시한다.
- 오늘 완료율은 오늘 날짜 기록 기준, 없으면 0%다.
- 연속 기록은 오늘 또는 가장 최근 기록부터 날짜가 이어지는 기록 수로 계산한다.

## 몸 상태(증상) 항목 — 2026-09-11 추가

- "손 저림 또는 힘 빠짐" 체크 항목을 4개 체크리스트와 별도의 "몸 상태" 섹션으로 둔다.
  - 목표 달성(체크할수록 좋음)을 의미하는 체크리스트 4항목과 달리, 증상 체크는 반대 의미(체크될수록 주의 필요)이므로 **완료율 계산에는 포함하지 않는다.**
  - 다만 기록이 하나라도 있으면(체크/기분/메모와 동일하게) 캘린더 점 표시 대상에는 포함한다.
- 이 항목을 체크하면 "발생 시각"(시/분 드롭다운 + "지금" 버튼, 분은 5분 단위)과 "지속 시간"(선택: 30초 / 1분 / 2분 / 3분 / 3분 이상) 입력이 추가로 나타난다.
  - 체크 해제 시 두 값은 저장하지 않고 비운다(오래된 값이 남지 않도록).
- 진단처럼 보이지 않도록 항목 아래 안내 문구를 둔다: "참고 기록용이며 진단이 아니에요. 증상이 심하거나 갑자기 나타났다면 병원 진료를 받아보세요."

## 반응형 요건 — 2026-09-11 추가

- 320px 폭까지 레이아웃이 깨지지 않아야 한다(가로 스크롤·요소 겹침·잘림 없음).
- 요일 헤더 그리드와 날짜 그리드는 항상 동일한 열 간격(gap)을 사용해 컬럼이 어긋나지 않아야 한다.

## 구현 제약

- 프레임워크 의존성을 최소화한 정적 웹앱으로 구현한다.
- 브라우저 기본 기능과 localStorage를 활용한다.
- 외부 API, 로그인, 개인정보 서버 전송은 범위에서 제외한다.
