## 변경 파일

- `index.html` — 전체 화면 구조(요약 카드, 월간 캘린더, 체크리스트 폼, 하단 안내 문구)
- `app.js` — 날짜 유틸리티, localStorage 저장/복원, 캘린더 렌더링, 완료율·연속 기록 계산, 폼 저장/삭제 로직
- `styles.css` — 모바일 우선 반응형 레이아웃, 따뜻한 그린 톤 디자인 토큰, 라이트 테마 고정
- `index.html` / `app.js` / `styles.css` (추가 반영) — "몸 상태" 섹션에 손 저림·힘 빠짐 증상 체크 항목 추가
  - 완료율(4개 체크리스트 항목) 계산에는 포함하지 않음 (목표 달성 지표와 증상 체크는 의미가 반대이므로 분리)
  - 안내 문구 추가: "참고 기록용이며 진단이 아니에요. 증상이 심하거나 갑자기 나타났다면 병원 진료를 받아보세요."

## 검증 결과 (Chrome, `python3 -m http.server`로 로컬 정적 서빙 후 테스트)

- [x] `index.html`을 브라우저에서 실행 가능 (`localhost:8934/index.html`)
- [x] 오늘 날짜(2026-09-11) 기본 선택 확인
- [x] 체크리스트 2개 체크 + 기분 선택 + 메모 입력 후 저장 → 완료율 50%, "저장되었습니다" 상태 메시지 확인
- [x] 새로고침 후 체크 상태·기분·메모가 그대로 복원됨 (localStorage 영속성 확인)
- [x] 캘린더에 기록 있는 날짜(9/11)에 점 표시 확인
- [x] 다음 달(10월) 이동, "오늘로 이동" 버튼으로 복귀 정상 동작
- [x] `document.documentElement.scrollWidth === window.innerWidth` 확인 → 가로 스크롤(레이아웃 깨짐) 없음
- [x] 손 저림/힘 빠짐 항목 추가 후 저장·복원·완료율 영향 없음(4개 항목 기준 유지) 확인
